# Genesis · Supervisor

Clickable prototype of the **Supervisor** platform for Landlord Service Plans (Genesis). It follows the client-approved "Dashboard Variation 04" design: Montserrat, LSP navy, blue and green, and real home photography.

## Screens
| Group | Screens |
|---|---|
| Start | Sign in, 6-digit security code, locked account |
| Overview | Today (approved dashboard) · Team Work · Enquiries |
| Homes & People | Landlords (list, record, new-landlord wizard) · Lettings (6-stage board) · Tenants (8-step move-in) · Properties (Managed / Unmanaged, home record) |
| Partners & Work | Sign-Ups · Letting Agents (requests, quotes, invoices) · Contractors & Jobs · Inspections |
| Checks & Money | Approvals & Budgets · Safety Checks · Rent & Invoices |
| Records | Records & History · Support Access · Reports |

Sign in with any email and password. The security code is `123456`.

## Run locally
```bash
pnpm install
pnpm dev
```
